# Contoh

File runnable tersedia di folder `examples/`:

| File | Topik |
|---|---|
| `quickstart.py` | Ask minimal |
| `search_suggest.py` | Search dan autocomplete |
| `search_verticals.py` | Semua vertical search |
| `streaming.py` | Event streaming |
| `multi_turn.py` | Percakapan lanjutan |
| `multimodal.py` | Input gambar |
| `configuration.py` | Konfigurasi dan proxy |
| `mcp_server.py` | MCP server |

```bash
uv run python examples/search_verticals.py
```
