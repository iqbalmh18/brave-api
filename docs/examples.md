# Examples

Runnable examples are available in `examples/`:

| File | Topic |
|---|---|
| `quickstart.py` | Minimal Ask usage |
| `search_suggest.py` | Web search and autocomplete |
| `search_verticals.py` | Web, images, news, videos, and Goggles |
| `streaming.py` | Streaming events |
| `multi_turn.py` | Follow-up conversations |
| `multimodal.py` | Image input |
| `configuration.py` | Configuration and proxies |
| `mcp_server.py` | MCP server |

```bash
uv run python examples/search_verticals.py
```
