# 示例

可运行示例位于 `examples/`：

| 文件 | 主题 |
|---|---|
| `quickstart.py` | 最小 Ask 示例 |
| `search_suggest.py` | 搜索和自动补全 |
| `search_verticals.py` | 所有搜索 vertical |
| `streaming.py` | 流式事件 |
| `multi_turn.py` | 多轮对话 |
| `multimodal.py` | 图片输入 |
| `configuration.py` | 配置和代理 |
| `mcp_server.py` | MCP 服务器 |

```bash
uv run python examples/search_verticals.py
```
